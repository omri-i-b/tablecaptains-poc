Delegated Group Guest Management

A revised POC built for the mass-market gala workflow — sponsors and donors take ownership of a chunk of slots, fill names progressively over months, and the organizer keeps oversight without being in the middle of every change.

Public-facing surfaces

Sponsor checkout →
Public on-ramp. Sponsorship tiers, quantity, host details, pay-by-card or invoice-me.
Guest RSVP form →
What invited guests see in their email link. Name, dietary chips, accessibility, plus-one, connection note.

Host (table captain) surface

Host portal →
What a sponsor / host sees after they buy. Multi-table switcher, invite + add + edit, dietary + accessibility, replace, move guests between own tables, reminder banner.

Organizer surfaces

Groups overview →
Cross-group dashboard. Cutoff banner, completion %, final headcount, drawer with editable roster + reassign host + archive, bulk host import, nudges.
All guests →
Flat searchable list across every group. Type filter (host/guest), pending/dietary/accessibility filters, edit, replace, group reassign, CSV export.

The five-phase workflow this supports

  1. Phase 1 · Delegate. Organizer creates groups and assigns each to a host (sponsor, donor, board member, captain).
  2. Phase 2 · Recruit. Hosts invite by email, add guests manually, and capture dietary/accessibility info. Hybrid — not all guests self-register.
  3. Phase 3 · Chase & finalize. Organizer nudges stalled groups, drops in walk-ins, and watches the completion meter.
  4. Phase 4 · Spatial planning. (Separate workflow layer — out of scope for this MVP. Currently Miro / spreadsheets.)
  5. Phase 5 · Check-in & day-of. (Existing RSVPify check-in flow — not redesigned here.)

How this differs from v1

v1 lives at ../tablecaptains-poc/ — that one was built for FMM's specific cultivation-event model (free-form group sizes, plus-one courtesies, connection-to-cause emphasis). v2 reframes around Team Rubicon's mainstream workflow: fixed-capacity slots assigned by organizer, dietary/accessibility front-and-center, replace + move flows, hybrid entry, late editability through cutoff.
